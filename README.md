# crystal
Encrypted markdown vault in TUI with Obsidian-like features

**Documentation:** <https://tuna-guven.github.io/crystal/>: design, threat
model, setup and the decision log. Sources are in [`docs/`](docs/SUMMARY.md);
build locally with `mdbook build` or `mdbook serve --open`.

**Status:** in development, not ready for real notes. See the
[roadmap](docs/development/roadmap.md).
